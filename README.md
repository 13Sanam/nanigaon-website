# Nanigaon Website V4.2 — final static storefront

Open `index.html` after extracting the ZIP. Upload the contents of this folder (not the ZIP itself) to GitHub. Connect the repository to a static hosting service.

## Features
- 4 auto-rotating and swipeable hero banners
- 5 product cards with variants and full-size product images
- Local Mandla PIN 481661 for fresh items; India-wide ghee enquiry with shipping to be confirmed
- Cart, WhatsApp checkout, optional GPS location, and WELCOME10 estimated discount
- 15/30-day milk subscriptions, glass bottle return agreement, coupon calculator
- Visual story slider, contact details and original product imagery

## IMPORTANT: Not a production backend
This is a STATIC WEBSITE. Prices/cart are stored locally in the customer's browser. WELCOME10 is a visible estimate only; the seller must verify household first-order eligibility and final payment amount. Courier serviceability, shipping cost, GPS accuracy, and UPI payment confirmation are manual. There is NO secured admin panel, server-side database, login, real order tracking or automatic payment verification. Do not publish the previous admin.html demo as a real admin panel.

For independent product updates and secure coupon redemption, build a separate authenticated admin backend and database before claiming those features are operational.
